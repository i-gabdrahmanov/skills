# 021 — Локальный конфигуратор Forge

**Статус — реализовано.** Каталог и границы покрытия описаны в [документации](../docs/forge-config.md).

Из терминала проекта человек запускает `forge-config`. Python-приложение находит проект, занимает свободный локальный порт, печатает адрес и открывает его в браузере. В интерфейсе человек видит доступные настройки, понимает последствия каждого выбора и может проверить изменение перед записью.

## 1. Определить покрытие настроек

Начни с [реестра параметров](../skills/config-helper/references/params-registry.json), [команд config-helper](../skills/config-helper/scripts/config.py) и [маршрутизации файлов](../skills/config-helper/scripts/_util.py). Составь таблицу «настройка или операция → допустимые значения → источник правил → файл и область действия → элемент формы». Сверь её с фактическими потребителями настроек и документацией расширений. Учти структурные операции с фазами и рисками, которые могут отсутствовать среди скалярных параметров. Для найденной пользовательской настройки вне реестра укажи её штатный механизм редактирования. Служебные результаты запусков и тестовые данные исключи из каталога.

**Приёмка.** Для каждого ID реестра, в том числе отсутствующего в JSON проекта, определено представление. Для каждого конечного списка известны все варианты, для свободного ввода — формат и ограничения. Условия доступности привязаны к версии, расширению или выбранной фиче там, где это влияет на поведение.

## 2. Подключить Python к существующей логике Forge

Используй общий код CLI для чтения, проверки и записи. Если нужная операция связана с argparse, выдели общую функцию и сохрани поведение CLI. Для корня проекта и приоритета policy.json/pipeline.json следуй [загрузчику Forge](../hooks/_config_loader.py). Различай настройки проекта, установки и конкретной фичи. Покажи целевой файл перед записью. Для manifest предложи выбор существующей пары skill/feature и проверяй её на сервере. Учитывай ограничения действующего запуска, подтверждения человека и правила чувствительных настроек.

**Приёмка.** На временном проекте значения после сохранения читаются штатным Forge. Неизвестные ключи сохраняются. Повреждённый JSON даёт ошибку с именем файла до записи. Просмотр каталога ничего не создаёт и не мигрирует.

## 3. Реализовать запуск одной командой

Добавь терминальную команду `forge-config` в поддерживаемый процесс установки. Проверь её обнаружение через PATH в новой оболочке и запуск из вложенного каталога проекта. Подбирай Python по правилам установки Forge. Привяжи сам HTTP-сервер к 127.0.0.1 с портом 0. Проверь выданный ОС порт до открытия браузера. Если это 8080 или 8084, закрой сокет и повтори привязку. Сохрани принятый сокет на всё время работы. Когда сервер готов, выведи URL и один раз вызови стандартный модуль webbrowser. Если браузер недоступен, оставь адрес для ручного открытия. Ctrl+C должен освобождать порт.

**Приёмка.** Два одновременных запуска обслуживают разные адреса. Проверка с подставным браузером подтверждает доступность страницы при открытии. Отдельно воспроизведи выдачу обоих запрещённых портов. Проверь обновление и удаление установленной команды.

## 4. Собрать форму и написать подсказки

Покажи вверху путь проекта и выбранную область. Сгруппируй настройки по категориям реестра. Для каждого поля показывай название, эффективное значение и источник значения. Переключатель подходит для bool, список — для enum, числовое поле — для диапазона. Для вложенных структур используй подписанные поля. Покажи зависимые варианты с объяснением, при каком условии их можно выбрать.

У каждого поля размести кнопку «?» с подсказкой по-русски. Объясни, что меняется, кого затрагивает изменение и какой пример значения корректен. Для вариантов с разным поведением объясни смысл каждого. Подсказка открывается наведением, фокусом и нажатием, закрывается по Escape и доступна с клавиатуры. Добавь поиск по названию, ID и aliases, фильтр «Только изменённые» для черновика и возможность отменить правку до сохранения.

**Приёмка.** На чистом проекте человек находит «покрытие», видит диапазон 0–1 и значение по умолчанию 0,8, вводит 0,85 в поддерживаемом формате и видит, в какой файл попадёт 0.85. Ошибка диапазона объясняется рядом с полем.

## 5. Сделать сохранение предсказуемым

Перед подтверждением покажи файл, ключ и переход от старого значения к новому. Маскируй чувствительные данные в форме, предварительном просмотре и логах. Сохраняй изменения по одному целевому файлу за подтверждение. Валидируй весь набор до записи, проверяй изменение файла с момента чтения и используй атомарную замену под общей блокировкой для экземпляров UI. При конфликте сохрани черновик и предложи перечитать файл. Разрешай запись только для известных операций и целей, проверяй источник запроса и токен локальной сессии.

**Приёмка.** Отмена, ошибка в одном поле или конфликт с другим экземпляром оставляют файл целым. После успешной записи интерфейс перечитывает эффективные значения.

## 6. Проверить установленное приложение

Расширь тесты рядом с config-helper и установщиком. Покрой соответствие каталога реестру, типы и варианты, legacy-проект, выбранный manifest, отказ штатной защиты и цикл «открыть → изменить → сохранить → открыть заново». Проведи ручной проход в браузере только с клавиатурой. В инструкции установки добавь команду запуска, выбор проекта, ручное открытие URL и остановку процесса.

**Порядок сдачи.** Сначала согласуй покрытие задачи 1 с кодом. На этой основе выполни задачи 2 и 3, затем 4 и 5. Заверши задачей 6. В отчёте Sol укажи проверенные способы установки, команды тестов и фактические результаты ручного прохода.

## Проверка реализации

- `python3 -B -m unittest discover -s skills/config-helper/scripts -p 'test_*.py'` — 26 тестов прошли. Для HTTP-тестов нужен доступ к локальным сокетам.
- `python3 -B -m unittest test_install_kinds` — 6 тестов прошли, включая запуск команды через PATH после установки и обновления и её удаление при uninstall. Установки проверены с `--no-link`, обновление с `--no-pull`.
- Chrome в headless-режиме с эмуляцией клавиатуры — поиск, открытие подсказки по фокусу, закрытие по Escape, редактирование, предпросмотр и сохранение. Содержимое policy.json проверено после записи.
