# upz-adapter

## 1. Общее описание

УПЗ-адаптер — шлюз между сервисами и внешней системой УПЗ (управление поручениями и задачами).

## 2. REST API

### 2.1 POST /api/v1/upz/tasks — создание задачи в УПЗ

Принимает запрос на создание задачи и передаёт его во внешнюю систему УПЗ. Ответ УПЗ приходит
асинхронно: адаптер публикует его в топик `pprbkid.upz.task.response.v1`.

| поле | тип | описание |
|---|---|---|
| taskType | string | код типа задачи |
| vspCode | string | код ВСП |
| dueDate | date | срок исполнения |

Ответ `202` — запрос принят.
