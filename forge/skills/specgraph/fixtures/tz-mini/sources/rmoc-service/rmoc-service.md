# rmoc-service

## 1. Общее описание

rmoc-service — сервис рабочего места РМОЦ: хранит упаковки и их движение между ВСП, РМОЦ и СЦ-архивом,
отдаёт данные экранам задач.

## 2. REST API

### 2.1 GET /rmoc/packages — упаковки к передаче

| параметр | тип | обязательный | описание |
|---|---|---|---|
| vspCode | string | да | код ВСП |
| status | string | нет | статус упаковки |

Ответ `200`:

```json
[
  {"packageId": "PK-001", "status": "К передаче в архив", "barcode": "4600000000017"}
]
```

### 2.2 POST /rmoc/packages/transfer — передача упаковок в СЦ-архив

Фиксирует передачу набора упаковок в СЦ-архив и переводит их в статус «Передано».

```json
{"vspCode": "1234/0567", "packages": ["PK-001", "PK-002"]}
```

Ответ `200`; `400` — упаковка не найдена.

### 2.3 GET /rmoc/komplekt/items — состав укомплектования

Возвращает позиции, которые сотрудник должен укомплектовать по задаче.

Ответ `200` — массив `{itemId, name, quantity}`.
