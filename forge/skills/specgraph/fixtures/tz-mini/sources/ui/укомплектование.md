# UI укомплектования

Экран работы с задачей «Укомплектование».

## Список задач

Показывает открытые задачи сотрудника. Данные — `GET /api/v1/tasks` (task-service) с фильтром по типу
`KOMPLEKT`.

## Карточка задачи

Состав укомплектования загружается вызовом `GET /rmoc/komplekt/items` (rmoc-service).

Кнопка «Завершить» вызывает `POST /api/v1/tasks/{id}/complete` (task-service). При ответе `409` экран
показывает «Задача уже закрыта».
