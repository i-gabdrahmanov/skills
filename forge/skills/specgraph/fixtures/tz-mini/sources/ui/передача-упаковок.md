# UI передачи упаковок

Экран работы с задачей «Передача упаковок в СЦ-архив».

## Упаковки к передаче

Список упаковок ВСП загружается вызовом `GET /rmoc/packages` (rmoc-service) со статусом «К передаче в
архив».

## Передача

Кнопка «Передать» вызывает `POST /rmoc/packages/transfer` (rmoc-service) с выбранными упаковками.

Кнопка «Завершить задачу» вызывает `POST /api/v1/tasks/{id}/complete` (task-service).
