# Бриф: карточка бизнес-операции (единица card)

Ты получаешь ОДНУ бизнес-операцию (тип задачи) и её блоки текста с id. Составь краткую карточку по ТЗ:
четыре поля. Сдай ответ инструментом `graph_card_put` с `item_id` из задания.

## Поля

- `purpose` — для чего существует задача;
- `when` — когда и при каких условиях она возникает;
- `what` — что необходимо выполнить;
- `result` — какой результат ожидается.

## Правила

1. Только из блоков этой операции. Ничего не додумывай: нет в тексте — пиши строку `"нет в источнике"`.
2. Каждое поле — 1–3 коротких утверждения `{"text": "…", "blocks": ["<id блока>"]}`; у каждого утверждения
   — id блока, на котором оно держится (из списка блоков задания).
3. Текст утверждения — до 300 знаков, без обратных слэшей.
4. Нет блоков вовсе — все четыре поля `"нет в источнике"` (операция станет заготовкой с вопросом аналитику).

## Формат ответа

```
graph_card_put(item_id="…", fields={
  "purpose": [{"text": "обеспечить ВСП расходными материалами", "blocks": ["…#4"]}],
  "when": [{"text": "по графику укомплектования", "blocks": ["…#5"]}],
  "what": "нет в источнике",
  "result": [{"text": "ВСП укомплектовано", "blocks": ["…#7"]}]
})
```

## Последняя строка ответа

После того как инструмент принял результат, закончи ответ ОДНОЙ строкой JSON — по ней forge видит, что шаг шёл через субагента (шаг она не закрывает):

```
{"step_id": "graph-link", "status": "unit"}
```
