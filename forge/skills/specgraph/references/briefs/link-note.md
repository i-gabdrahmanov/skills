# Бриф: связи одной заметки (единица link-note)

Ты получаешь ОДНУ заметку графа: её вид, допустимые рёбра, дословный текст, подсказки — какие узлы
упомянуты в тексте, — список бизнес-операций и рёбра, уже поставленные правилами. Предложи рёбра от этой
заметки. Сдай ответ инструментом `graph_link_put` с `item_id` из задания.

## Правила

1. Ребро — только для ВЗАИМОДЕЙСТВИЯ, которое текст описывает: вызывает, публикует, читает, формирует
   задачи, закрывает задачи, запускает, использует данные, является UI задачи. Простое упоминание
   («см. также», «связано с сервисом») — не ребро.
2. `creates_task` / `closes_task` — только если текст говорит о создании или закрытии задач ЭТОГО типа.
   Общий шедулер, закрывающий задачи нескольких типов, даёт по ребру на каждый тип из текста.
3. `ui_of` — у экрана: задача, с которой он работает. `related` — у бизнес-операции: другая операция,
   с которой текст её связывает.
4. `invokes` — запуск алгоритма или отдельно описанной отправки сообщения ТОГО ЖЕ сервиса.
5. У каждого ребра — `quote`: ДОСЛОВНЫЙ кусок текста заметки (от 20 знаков), на котором ребро держится.
   Цитата не из текста — отказ всей единицы.
6. `to` — имя узла из подсказок или из списка операций; можно ключ (`POST /path`, `task:КОД`).
   Не уверен в цели — всё равно предложи: неоднозначное уйдёт человеку вопросом.
7. Не повторяй рёбра, уже поставленные правилами. Рёбер нет — сдай пустой список.
8. В строках нет обратных слэшей и управляющих символов.

## Формат ответа

```
graph_link_put(item_id="…", proposals=[
  {"edge": "closes_task", "to": "Регистрация", "quote": "`REGISTRATION` (Регистрация)",
   "confidence": "high", "why": "закрывает регулярные задачи этого типа"}
])
```
