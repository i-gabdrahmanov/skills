Запусти скилл specgraph — это spec-graph, граф спецификации в репо спеки. Конвейер: graph-map →
graph-link → graph-check, на каждом шаге одно решение человека. НЕ спрашивай, какой путь выбрать.

Scope прогона (all | имя сервиса | файл; пусто — all):
{{args}}

Первый ход — `graph_status` (MCP spec-graph). Проект не инициализирован — первый запуск: задай
пользователю вопросы из ответа (кандидаты с доказательствами предлагай первыми, решает он), затем
`graph_init` с ответами. Корни спеки, исключения и путь vault не угадывай.

Заметки графа и `.spec-graph/` руками не пиши — только инструментами `graph_*`. Шаг закрывает
только его гейт (`graph_gate.py`), а не слова «готово».
