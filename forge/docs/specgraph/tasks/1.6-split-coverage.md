# 1.6 — Нарезка в vault и проверка полноты

**Этап:** 1 (graph-map) · **Зависит от:** 1.5, 0.3 · **Статус:** todo
**ТЗ:** §1, §8.1, §9.3–9.4, §9.8 · **Решения:** рычаг 1, D6, D8, D11
**Уроки:** инварианты 4, 11, 21, 22 прототипа

## Зачем
По утверждённому каталогу и плану раскладки (1.5) заметки пишет скрипт: текст дословно,
frontmatter по онтологии, ребро
`belongs_to` — из владельца. Полнота переноса (ТЗ §9.8) проверяется здесь механически, сверка роем
не нужна.

## Что сделать
- Инструмент `graph_split(scope)` (узлы дельты 1.5 нарезаются наравне с утверждёнными; если в
  отчёте связей 2.6 узел дельты слили, переименовали или убрали — повторная нарезка затронутых
  файлов, она идемпотентна):
  - путь заметки — `ontology.path_for` (vault из конфига, по умолчанию `docs/graph/`);
  - FM — все ключи вида из онтологии (рёбра пустыми `[]`: видно, что связь проверяли), `kind`,
    `status: draft`, `source` (список `файл#раздел`), `blocks`, `belongs_to` из владельца;
  - тело — заголовок-имя, затем `<!-- graph:source:start file=… blocks=… sha=… -->`, блоки
    дословно, `<!-- graph:source:end -->`; проза человека вне маркеров при повторной нарезке
    сохраняется;
  - заметка сервиса — блоки общего описания плюс `generated:toc` со списком операций по видам;
  - `_graph/unplaced.md` — неразмещённые блоки дословно, с источником: в vault всё равно ничего не
    теряется;
  - вложения `resources/…` копируются в `_attachments/`, ссылки переписываются; якорные ссылки
    `](#x)` переписываются в `[[заметка#заголовок]]`, если цель уехала в другую заметку. Все
    переписывания пишутся в `.spec-graph/rewrites.json`.
- Проверка полноты `.spec-graph/coverage.json` и раздел в `_graph/report.md`: по файлу — блоков
  всего / в узлах / `skip` (по причинам) / `unplaced` / не назначено. Дословность — `sha` каждого
  блока в заметке = `sha` блока исходника после обратного применения `rewrites.json`.
- `_graph/index.md` — реестр: `[[имя]]`, kind, сервис, key, status, путь.

## Готово, когда
- Фикстура: «не назначено» = 0, дословность — все блоки, число и `sha` код-блоков совпадают с
  исходником.
- Повторный `graph_split` даёт 0 изменений; проза, дописанная человеком вне маркеров, переживает
  повторную нарезку.
- Мутант «блок выпал из плана» → `E-coverage` с id блока; мутант «правка внутри source-маркера» →
  `E-verbatim`.
- Ссылки на вложения и якоря открываются в Obsidian (проверить руками на фикстуре, одна строка в
  «Результате»).
