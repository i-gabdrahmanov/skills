# 1.7 — Шаг graph-map: бриф, гейт, согласие

**Этап:** 1 (graph-map) · **Зависит от:** 1.6 · **Статус:** todo
**Решения:** D1, D13, D14, D23, D24; память: «фазы — субагентом», «enforcement > guidance»

## Зачем
Собрать 1.1–1.6 в один шаг конвейера с одним решением человека — утвердить каталог и scope после
разведки, до нарезки. Шаг закрывается только механическим гейтом, а не словами модели «каталог
готов».

## Что сделать
- Бриф шага в `skills/specgraph/SKILL.md`, порядок для оркестратора:
  1. `graph_survey` → цикл очереди `draft-file` (0.6) → `graph_catalog`;
  2. показать пользователю `_graph/catalog.md` (объём работ, `review`, предложенный scope) и
     спросить о решении → `graph_catalog_decide` → согласие;
  3. цикл очереди `assign-section` → `graph_split`.
  Вопросы субагентов идут через релей оркестратора, как в forge.
- `phase_tools` ветки `specgraph` для `graph-map`: `graph_draft_put`, `graph_assign_put`,
  `graph_split`. `graph_survey`, `graph_next`, `graph_queue_status`, `graph_catalog`,
  `graph_catalog_decide` вызывает оркестратор.
- Гейт очереди: `graph_assign_put` и очередь `assign-section` не работают, пока нет согласия
  `graph-catalog-<KEY>` на текущий снимок каталога. Нарезка до решения человека невозможна кодом.
- `graph_gate.py map`:
  - очереди `draft-file` и `assign-section` закрыты (`queue_closed`), брошенные перечислены;
  - согласие привязано к `catalog.approved.json` (`--bind-file`);
  - нарезка сделана по этому снимку плюс дельта;
  - «не назначено» = 0;
  - FM всех заметок читается кодеком.
- Изменился снимок каталога после согласия — согласие устарело, гейт не пускает. Дельта новых узлов
  снимок не меняет: по ней решают в 2.6.

## Готово, когда
- Тесты гейта: нет согласия → блок; снимок изменён после согласия → блок; очередь не закрыта →
  блок; покрытие < 100 % → блок; всё на месте → exit 0.
- `graph_assign_put` до согласия — отказ (тест).
- Шаг на фикстуре с заранее записанными ответами (`expected/drafts/`, `expected/plans/`)
  проходит до exit 0, включая «обрыв» посреди очереди и продолжение.
- Hook-тесты зелёные, evals дополнены сценарием «модель режет до утверждения каталога».
