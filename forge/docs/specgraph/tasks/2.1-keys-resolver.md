# 2.1 — Ключи склейки и резолвер

**Этап:** 2 (graph-link) · **Зависит от:** 1.6 · **Статус:** done
**ТЗ:** §1.3, §8.5 · **Уроки:** инвариант 7 и раздел «Ключи и имена» прототипа, нормализация режима C

## Зачем
Межсервисные связи склеиваются по машинному ключу, а не по имени файла. Спека пишет «вызывает
POST /api/v1/tasks УПЗ-адаптера», а узел называется `upz-adapter POST api-v1-tasks`. Резолвер
превращает упоминание в узел — или честно говорит «неоднозначно» / «нет такого узла». Молча
выбирать нельзя.

## Что сделать
- `sgraph/keys.py`:
  - `http:<METHOD> <path>`: метод в верхнем регистре, путь без хоста и без завершающего `/`,
    `{любое}` → `{}`, версия в пути сохраняется. Срезаемые префиксы (gateway, `/api`) — один раз на
    vault в конфиге `http.strip_prefixes` и строкой в `_graph/decisions.md`;
  - `kafka:<name>` (и `amqp:<exchange>/<routing-key>`, если встретится);
  - `task:<код типа задачи>`.
- `sgraph/resolve.py`: упоминание (ключ, имя, алиас) → `node` | `ambiguous[кандидаты]` | `ghost`.
  Нечёткое совпадение пути (ratio ≥ 0.93) → подсказка `path_typo`, автоматически не применяется.
  Индекс ключей строится из FM vault.
- Инструмент `graph_resolve(mentions[])` — короткий ответ по каждому упоминанию.

## Готово, когда
- Таблица нормализации из прототипа (регистр, хвостовой `/`, `{id}` vs `{taskId}`, gateway-
  префикс) — тестом.
- Неоднозначность никогда не разрешается сама: тест «два эндпойнта с одним путём в разных
  сервисах без указания сервиса → `ambiguous`».
- Опечатка пути даёт `path_typo` с кандидатом, но не узел.

## Результат
- `sgraph/keys.py` (с 1.2): `http_key`, `norm_path`, `find_http`, `endpoint_name`, `topic_key`, `task_key`.
- `sgraph/resolve.py`: `vault_index` — узлы из frontmatter vault (вид, роль, подвид, key, алиасы, сервис
  из `belongs_to`, путь; основа обхода 3.4); `resolve` — `METHOD /path` (с префиксами `http.strip_prefixes`
  и с обеих сторон), `kafka:`/`task:`/`http:` ключ, имя топика, код типа задачи, имя или алиас узла
  (регистр, ё/е) → `node`; несколько — `ambiguous` с кандидатами (сервис-контекст сужает до своего);
  нет — `ghost`, при похожем пути (ratio ≥ 0.93) с подсказкой `path_typo` и кандидатами.
- Конфиг: ключ `http.strip_prefixes` (пути с ведущим `/`) — решение один раз на vault.
- Инструмент `graph_resolve(mentions, service?)` — свободный (читающий).
- Тесты `test_keys_resolver.py` (7); мутанты (неоднозначность и опечатка решаются сами, префиксы не
  срезаются) пойманы. Урок X.1 `P-inv-7` → covered.
- Запись срезаемых префиксов в `_graph/decisions.md` — вместе с отчётом связей (2.6).
