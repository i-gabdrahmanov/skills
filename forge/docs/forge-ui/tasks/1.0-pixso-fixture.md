# 1.0 — Фикстура образца Pixso (обезличенная)

**Этап:** 1 · **Зависит от:** — · **Статус:** done
**Спека:** §19.3 (golden-фикстуры) · **QG:** F1 (база)

## Зачем
Все тесты этапа 1 опираются на настоящий Pixso DSL, а образец пользователя (`docs/daiver/dsl.json`) —
корпоративный дизайн и в git не едет. Нужна обезличенная копия той же структуры.

## Что сделать
- Скрипт `skills/forgeui/scripts/tools/anonymize_pixso.py <src> <dst>`: детерминированно заменяет
  идентификаторы библиотеки — `publishFile`, `publishID`, `componentKey`, `overrideKey` — на
  фиктивные (`sha256(соль + значение)[:N]`, одинаковое → одинаковое, ссылки сходятся); `guid` и
  структуру не трогает; тексты — по флагу `--keep-texts` (по умолчанию заменяет на «Текст N»
  той же длины по словам, кроме чисел — числа нужны тестам раскладки).
- Усечение: из `pixComponentTreeDslNodes` — только определения, достижимые из экрана.
- `skills/forgeui/fixtures/pixso-modal/`: `dsl.json` (обезличенный), `README.md` (откуда, что
  заменено, какие поля проверяют тесты). Растр и SVG не кладём — для визуальных тестов будут
  синтетические картинки (этап 5).
- После 1.3–1.5 — `canonical.golden.json` (эталон нормализации, ревьюится глазами один раз).

## Готово, когда
- Тест: в фикстуре нет ни одного исходного значения `publishFile/componentKey/overrideKey`
  (сверка с оригиналом — только если `docs/daiver/dsl.json` есть локально, иначе skip с причиной).
- Повторный запуск скрипта даёт побайтно тот же файл.
- Структура (типы узлов, guid, ссылки mainComponent/pathString) совпадает с оригиналом.

## Вопросы
- Тексты образца («Место хранения…») — бизнес-копия, не PII. Если их можно оставить — `--keep-texts`
  делает тесты материализации нагляднее. Решает пользователь.

## Результат
- `daiver/pixso/dsl.py` — общие хелперы над DSL (`unwrap`, `walk`, индексы владельцев и publishID,
  достижимость определений, `prune_definitions`); тот же код использует slim в 1.2.
- `daiver/pixso/anonymize.py` + CLI `tools/anonymize_pixso.py`; самопроверка утечек — при остатке
  исходного значения (в том числе подстрокой) файл не пишется, exit 3.
- Фикстура `fixtures/pixso-modal/dsl.json` и README с устройством образца.
- Отклонения: тексты заменены по умолчанию (вопрос оставался открытым; `--keep-texts` для оставить);
  шрифт `SB Sans Text` переименован в `Fixture Sans` (`--font`); растр и SVG в фикстуру не вошли.
- Формат оказался богаче описанного в спеке: `publishID == overrideKey`, слоты типа `instance`
  ссылаются publishID, `pathString` — цепочка через `/` — всё в README фикстуры.
- `canonical.golden.json` появится после 1.3–1.5.
