# X.1 — Матрица инвариантов

**Этап:** сквозная · **Зависит от:** — · **Статус:** done
**Спека:** §18 (135 INV), §19.8 (механическая проверка покрытия)

## Зачем
«Сделали всё» должно проверяться кодом: у каждого из 135 инвариантов спеки — тест, именованная
деградация или задача, в которой он будет закрыт.

## Что сделать
- `skills/forgeui/references/inv-matrix.json`: на каждый id A1–A13, B1–B23, C1–C39, D1–D10, E1–E8,
  F1–F20, G1–G12, H1–H10 — `{status: covered|degraded|planned, tests:[…], task:"4.6", note}`.
  Сразу: covered — уже закрытое Этапом 0 (B19, B20, A5, часть C36…); degraded — телеметрия (H1–H10,
  C37, F19, G5–G7, G9, G12) и autoRoute (A12) с причиной; остальное — planned со ссылкой на задачу.
- `skills/forgeui/scripts/test_inv_matrix.py`: все 135 id на месте и без лишних; у covered —
  существующие файлы тестов; у degraded — причина; у planned — существующий файл задачи в
  `docs/forge-ui/tasks/`. Финальная приёмка (после этапа 7): planned не остаётся.
- Каждая задача, закрывая инвариант, переводит его в covered — часть Definition of Done.

## Готово, когда
- Матрица заполнена, тест зелёный, README задач ссылается на неё.

## Результат

- `skills/forgeui/references/inv-matrix.json` — 135 записей (строка на инвариант, порядок §18): **covered 106**,
  **degraded 19**, **planned 10**. Ссылка на тест — `<файл>::<Класс>` (движок — `skills/forgeui/scripts/`, хуки —
  `hooks/`); `task` — где закрыт (у принципов и Этапа 0 — без задачи).
- **degraded** — телеметрия §17 (H1–H10, C37, F19, G5–G7, G9, G12: forge снял логи), autoRoute (A12) и строка-анонс
  (F20, часть маршрутизации; тихое скольжение в фазу режут `ui-guard` WriteStep и `phase_tools`).
- **planned** — X.4 (поведение модели, держится только брифом): A2 (запрет читать исходники библиотеки напрямую —
  хуком не форсится), A9 и F18 (конвенции проекта, «домашний стиль»), B9 (корневой px не хардкодится), C11 (пролог),
  C15 (семантика по `tag`), C16 (тексты не хардкодятся в разметку), C17 (data-секции prop-driven), D5 (человеческий
  шаг не в таск-листе); X.2 — F10 (Figma REST: кода Figma нет, статическая проверка — вместе с адаптерами).
- `skills/forgeui/scripts/test_inv_matrix.py` (8): все 135 id на месте, без лишних и по порядку; у covered — файл
  теста, класс верхнего уровня с собственными test-методами (разбор `ast`); у degraded/planned — причина; каждая
  названная задача есть в карте README и файлом; **planned указывает только на незакрытую задачу** — закрытие
  задачи с открытым инвариантом валит тест, финальная приёмка «planned не осталось» наступает сама; строка
  отклонения §17 в README и degraded-телеметрия матрицы совпадают поимённо. Мутации: 17 из 17 убиты (пропуск id,
  лишний id, порядок, неизвестный статус, covered без тестов, несуществующие класс/файл, класс без тестов,
  не-тестовый путь, degraded без причины, planned без задачи / на закрытую задачу, неизвестная задача, расхождение
  с README §17, дубль теста, лишнее поле, закрытая X.4 при planned).
- Пробел, найденный сверкой: INV-E5 («maxVerifyIterations игнорируется в interactive») тестом не пинился —
  `test_autonomous_triage.py::InteractiveHasNoCap` (четыре итерации человека при потолке 3: остановки нет,
  открывается пятая).
- Устаревшее по ходу: строка README «§12.3 resolutions/signature» и докстринг `plan_contract.py` говорили
  «автономия ещё не построена» — переписаны под 7.1/7.2; причина отклонения «поле `directive`» уточнена.
- Сверка была по классам и именам тестов, не по каждому assert: «covered» значит «есть тест на правило, которое
  держит код», а не «каждая фраза инварианта доказана». Остаток поведения модели (выбор waitMs, удаление removed,
  ремонт ровно по fix-строке…) — в note записи и в X.4.
