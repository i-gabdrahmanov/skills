# 7.1 — Директива и прогон: run.json, режимы, blocked с supply

**Этап:** 7 · **Зависит от:** этап 4 · **Статус:** todo
**Спека:** §15.1–15.3, §15.5, §15.6, §20.3 · **INV:** B22, C38, D2, D3, D5, D7, D10, E1–E8, G8 ·
**QG:** U11, S12, P5

## Зачем
forge-ui должен уметь работать без человека (таск-лист внешнего оркестратора, headless): все вопросы
заданы на плане, а всё, что без человека не решить, — именованная остановка, а не догадка.

## Что сделать
- Инструмент **`daiver_directive(line)`** (превью разбора, ничего не пишет). Грамматика: префикс
  `forge-ui:` (алиас `daiver:`) `track=<KEY> [frame=<url>|file=<path>] [frame.<имя>=<url>…]
  [specs=<path>[,…]] [url=<url>] [url.<имя>=<url>…] [state.<имя>=<кадр>…] [revision[.<имя>]=<url>…]
  [sources[.<имя>]=<пути>] [scope=change|page] [until=resolve|build|verify] [from=plan]
  [mode=autonomous|interactive]`. Malformed — назван дословно, НИКОГДА не чинится: неизвестный ключ;
  ни frame, ни file для кадра без требования; `mode = autonomous` (пробелы); `autonomous=true`;
  `mode=auto`; `from=plan` вместе с `frame=`; недопустимый scope; revision рядом с frame= того же
  кадра; revision при from=plan; `state.x=x`; `state.main=…`. Ссылка state на кадр, которого строка
  не называет, — предупреждение. Нет `mode=` ≠ interactive: дефолт директивы — autonomous
  (`workflow.embeddedMode`); нераспознанное значение автономию не дарует никогда.
- Инструмент **`daiver_run(track|directive, finish?, blocked?)`**: открытие — ключи, mode+источник
  (строка > embeddedMode > workflow.mode), `startsAt` (build при from=plan или готовом плане;
  resolve при требовании без плана; track при макете в директиве; verify для собранного; done для
  чистого), политика (подпись плана: есть — ok, нет — `blocked: plan-unsigned`, отклонение D9),
  кадры; запись `run.json` (кто начал, режим и источник, директива дословно). Blocked — полный список
  §20.3 с `supply` (кто что даёт). Закрытие — outcome из ЗАПИСАННОЙ истории verify: clean |
  defects-remaining | blocked:<причина> | never-run; `until=` → never-run честно. Устаревший рекорд
  (начат директивой, а за клавиатурой человек) закрывается и открывается заново.
- Запреты автономии кодом (D3): `daiver_init`, `daiver_map_append`, `daiver_verify_report` в
  автономном прогоне отказывают; конфиг и карту не пишет `state-write-guard` (3.4).
  *Заметка (2.1):* сейчас `daiver_map_append` в автономии не пишет только потому, что некому дать согласие `ui-map-<KEY>`; явный отказ по
  режиму `run.json` добавить в `component_map.append` / `t_map_append` (режима в движке карты нет).
- Вход: `/forge forge-ui: track=… mode=autonomous` — бриф распознаёт директиву и зовёт `daiver_run`;
  headless — `--allowed-tools` (INSTALL.md §4) плюс MCP forge-ui.

`blocked: plan-incomplete (<id…>)` собирается из `blocks`, `blocked: plan-unsigned` — по `signed:false`; ответ контракта уже несёт оба в поле `blocked`.

свободных `PhaseToolsRegistry.FREE` (`hooks/test_branches_registry.py`) — пополнить. Запреты автономии (`daiver_init`, `daiver_map_append`) — отказ движка по режиму `run.json`; хук `state-write-guard` закрывает только запись файлов руками.
