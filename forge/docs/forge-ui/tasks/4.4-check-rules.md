# 4.4 — Правила проверки, допуски, dismissals, unverified

**Этап:** 4 · **Зависит от:** 4.3 · **Статус:** todo
**Спека:** §14.4.3, §14.4.4, §5.1 (`verify.tolerances`) · **INV:** C27, B16 · **QG:** U16, F3

## Зачем
Каждое правило куплено на реальных прогонах: ложный дефект так же вреден, как пропущенный. Всё,
что не стало дефектом, выводится с причиной — молча не дропается.

## Что сделать
`daiver/verify/check.py`:
- Коды и слои: structure (MISSING/EXTRA/ORDER/TEXT) → component (SLOT_MISSING, SLOT_TEXT,
  SLOT_TYPOGRAPHY, SLOT_COLOR, INVISIBLE) → token → geometry (SPACING, SIZE, POSITION, OVERFLOW) →
  typography → color → shape (SHAPE).
- Допуски из конфига, каждый со своим дефолтом: px 2, color 2 на канал (с альфой), fontSize 0.5,
  lineHeight 1, sizeRatio 0.01 (только размеры), sizeRatioMaxPx 8. «На грани» не срабатывает;
  размер в пропорции, но сверх капа — репорт.
- Доктрины §14.4.3 по списку: числовые — только на уверенных парах; сравнивается то, что компонент
  РЕНДЕРИТ (только overridden-слоты; SLOT_TYPOGRAPHY+SLOT_COLOR на двух слотах ячейки — подсказка
  «перепутаны caption/value»); SIZE на resolved-компоненте только при `sized:"own"`; согласный
  обеим сторонам внутренний padding/gap/radius/border — контракт библиотеки (dismissal), но
  INVISIBLE — дефект; выведенный размер (hug/fill/высота текста/line box шрифта) — dismissals,
  «тот же текстовый бокс короче» — репорт; padding по сторонам; margin vs gap при равных боксах —
  dismissal; корневой фрейм и «число макета больше комнаты родителя» — dismissal; типографика (первое
  семейство, пропущенный вес = Regular, text-align/lineHeight — только где обе стороны объявили);
  цвет (hex/keyword = rgba, нет заливки = transparent, градиент — текстом); форма (радиус — что рисует
  браузер, 50 % круг ≠ дефект, присутствие обводки и тени); текст (normalizeText, разная копия —
  critical, только регистр — dismissal, пустой слой не толкуется); overflow; падение правила →
  гейт degraded, остальные идут; «пар нет» — правила считаются исполненными.
- Unverified — третий выход: аспекты `content`, `copy`, `size` для инстансов без определения;
  зачитываются вслух рядом со счётчиком дефектов.
