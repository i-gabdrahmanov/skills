# 4.2 — daiver_screenshot, dom-snapshot.js, модель реализации

**Этап:** 4 · **Зависит от:** 4.1 · **Статус:** done
**Спека:** §14.3, §14.4.1, §14.2 (рецепты, clip), §20.4 (settleMs 400, domSettleMs 1500, pollMs 250,
навигация 30000, действие 5000, STABLE_SAMPLES 2, ACTION_VERBS) · **INV:** C22, C23, G10, D6, F13 ·
**QG:** U20

## Зачем
Снапшот — ЕДИНСТВЕННЫЙ источник измеренных значений пайплайна (геометрия, computed styles, тексты,
идентичность компонентов React), снимается каждую итерацию одним вызовом.

## Что сделать
- `daiver/assets/dom-snapshot.js` (исполняется в странице): цвета нормализуются в странице к
  `#RRGGBB[AA]` (нераспознанное — как есть); отсутствующая группа = дефолт (нулевые padding/gap/
  radius, shadow none, opacity 1 — опущены); результат — JSON-СТРОКА (CDP не носит граф глубже
  ~56); у каждого узла измеренный box в координатах страницы, size — числа; имя компонента из
  React fibers (минифицированное однобуквенное — не компонент; `react.found:false` — гейт
  идентичности не исполнялся); stamps `data-daiver-id` — вне документа (матчер их не читает); svg
  не обходится внутрь; пустая обёртка выбрасывается, с видимым содержимым — остаётся; id не
  сдвигаются после скрытого соседа; password читается; `line-height: normal` меряется; капы с
  флагом усечения; пустой корень — пустой документ; NaN невозможен.
- `daiver/verify/impl_model.py`: снапшот → модель формы канона (`sourceFormat: dom`, box у всех).
- Инструмент **`daiver_screenshot(track, frame?, url, iterationDir, waitMs, actions?, clipSelector?,
  waitForSelector?, waitForGone?, target?)`**: один вызов пишет `actual.png`, `actual.html`,
  `snapshot.json` (+ рецепт). Готовность: DOM перестал меняться И нет признаков загрузки
  (loader/spinner/skeleton/aria-busy/progressbar) в пределах `waitMs` (выбирает агент: холодный
  dev-сервер 60000+, обычно 25000, перепроверка 5000); `ready:false` — дефекты захвата не
  сравниваются; `elements` сверяется с числом узлов макета (недорисованная страница — находка);
  повторный идентичный вызов в ту же папку «подождать ещё» — отказ (поднимать waitMs).
  Рецепт: глаголы click, dblclick, hover, fill, press, select, waitFor, waitForGone, wait, scrollTo —
  без «выполнить JS». Шрифты макета проверяются `document.fonts` (нет SB Sans — предупреждение).

## Готово, когда
- `test_screenshot.py` на синтетических страницах (file:// или `python -m http.server`): ожидание
  исчезновения спиннера; clip; рецепт открывает диалог; поля снапшота; фейковые
  `__reactFiber$…` дают имена компонентов; повторный вызов в ту же папку — отказ (skip без Chrome).

*Заметка (3.4).* `daiver_screenshot` уже входит в `phase_tools` шага `ui-verify` (`hooks/_branches.py`): главный агент вызвать его не может, снимок делает субагент итерации. Каталог `verify/**` охраняет `state-write-guard`
(пишет только движок, `iterationDir` — под `.daiver/tracks/<KEY>/…/verify/`). Новый инструмент движка без решения «чей он» (шаблон в `phase_tools` или список свободных в `test_branches_registry.PhaseToolsRegistry.FREE`) роняет
`test_every_engine_tool_has_an_owner`.

*Заметка (4.1).* Браузер уже есть: `from daiver.browser import cdp as C`; `chrome, stop = C.launch_or_skip(cfg["verify"], root=root, viewport=(w, h), file_roots=[…])` →
`(Chrome, None)` либо `(None, stop)`, где `stop` — готовый ответ `blocked: no-browser` с `reason` / `supply` (инструмент возвращает его как есть, исключений на «браузера нет» не бывает). Закрывать `with chrome:` или
`try/finally chrome.close()` (иначе при выходе уберёт `atexit`, но не надейся). Вкладка: `page = chrome.new_page(url?, viewport=, nav_timeout=)`; `Page`: `navigate(url, wait="commit|domcontentloaded|load", timeout=)`,
`evaluate(выражение, await_promise=, timeout=)` (значение по значению; `dom-snapshot.js` вызывай им и возвращай JSON-СТРОКУ), `screenshot(clip=)` → PNG, `element_box`, `click`, `insert_text`, а всё остальное — `page.send("Домен.метод", {…})`,
события — `page.events()` / `page.wait_event()`. Диалоги страницы (alert/confirm/prompt/beforeunload) закрываются сами и записываются в `page.dialogs`. Таймауты — константы `cdp.NAV_TIMEOUT` (30 с) и `cdp.ACTION_TIMEOUT` (5 с)
из §20.4; сообщение клиента ограничено 128 МБ. Адрес проходит `check_url`: http(s), `data:`, `about:blank` и `file:` ТОЛЬКО внутри `file_roots` — для тестов на `file://` передай каталог фикстур. По умолчанию вкладка получает
viewport из `verify.viewport`, масштаб 1, `prefers-color-scheme: light` и `prefers-reduced-motion: reduce` — не менять между итерациями (INV-C23). Не фиксируются локаль и часовой пояс; шрифт `SB Sans` проверяется в
странице (`document.fonts`), а не браузером. Снимок тела страницы с `--font-render-hinting=none` и `--disable-gpu` не сверялся с обычным Chrome — сверить на первом настоящем экране.

## Результат
Захват реализации одним вызовом: страница → готовность → рецепт → снимок DOM → PNG/HTML/snapshot. Прогнано против настоящего Chrome (macOS) на синтетических страницах, не только против фейка.
Код: `skills/forgeui/scripts/daiver/verify/{capture,readiness,impl_model}.py`, `daiver/assets/dom-snapshot.js` (исполняется в странице, 736 строк), запись `daiver_screenshot` в `daiver/tools.py` (+ `_check_args` теперь понимает массив объектов — для `actions`), реестры в `hooks/` (`EXPECTED_TOOLS`, `phase_tools` шага `ui-verify`). Тесты: `skills/forgeui/scripts/test_screenshot.py` (**124 теста**, ~90 с с Chrome; без браузера захватные классы пропускаются).

- **`dom-snapshot.js`** отдаёт JSON-СТРОКУ (CDP не носит граф глубже ~56). Цвета нормализуются в странице к `#RRGGBB[AA]`, группы с дефолтами опущены, box в координатах страницы, имена компонентов — из React fibers (минифицированное однобуквенное — не компонент; `react.found: false` = гейт идентичности не исполнялся), stamps `data-daiver-id` вне документа, svg внутрь не обходится, капы с флагом усечения, пустой корень — пустой документ.
- **`impl_model.py`**: снимок → канон `sourceFormat: dom`; цвета → `rgba(...)`; `component {figmaName, implName, implNames}` (`implNames` — вся цепочка fiber от внешнего к внутреннему). Поля, которым нет места в каноне (`attrs`, `textBox`, `bgImage`, `scrolls`, `overflowing`, `cut`), остаются в `snapshot.json`. Правки `canon.py`: `font.textTransform` и `component.implNames` (только dom/code).
- **`readiness.py`**: готово = нет признаков загрузки + DOM не менялся 1500 мс + подпись содержимого одинакова в 2 замерах (константы §20.4). `ready: false` — ответ, не ошибка: файлы пишутся, дефекты такого захвата не сравниваются.
- **`capture.py`**: рецепт (глаголы `recipe.ACTION_VERBS`, «выполнить JS» нет), `clipSelector`, `waitForSelector`/`waitForGone`, `target: reference`, `sanity.underRendered` (элементов < 0.5 узлов макета), проверка шрифтов макета через `document.fonts`, предупреждения. Повторный ИДЕНТИЧНЫЙ вызов в ту же папку — отказ (отпечаток лежит в `snapshot.json`); `snapshot.json` пишется последним — он же метка «захват целиком». Браузера нет — ответ `blocked: no-browser` из 4.1 как есть.
- **Отклонения** — одна строка README (отпечаток, границы `waitMs`, `target: reference`); строка про `phase_tools` обновлена (`daiver_screenshot` теперь есть).

**Не проверено данными.** Порог недорисовки 0.5 и поведение на больших настоящих экранах (усечение по числу узлов, время снимка); production-сборки с минифицированными fibers; `SB Sans`; снимок с `--font-render-hinting=none` против обычного Chrome; как слабая модель выбирает `waitMs` и читает `ready: false` — всё это в README → «Нужно от пользователя» (4.2, X.4).
