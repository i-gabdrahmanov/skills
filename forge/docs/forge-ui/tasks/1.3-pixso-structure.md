# 1.3 — Pixso → канон: структура и геометрия

**Этап:** 1 · **Зависит от:** 1.1, 1.2 · **Статус:** done
**Спека:** §7.1, §7.2 (Структура, Геометрия), §6.3, §20.4 (`STRAY_ROOT_SHARE` 0.05, `ICON_MAX` 64) ·
**INV:** B2, B13 · **QG:** U2, F1

## Зачем
Единая точка входа нормализации: формат определяет код, агент адаптер не выбирает; на выходе —
схематически одинаковый канон для любого источника.

## Что сделать
- `daiver/ingest/detect.py`: pixso (сырой и slim) | figma-json-a | figma-json-b | figma-html |
  неизвестное → отказ с сообщением (не «лучшее усилие»). Figma — заглушки до X.2.
- `daiver/ingest/pixso.py` + инструмент **`daiver_normalize(track, frame?)`**: канон пишется в папку
  своего кадра (никакого outPath).
- Узлы: FRAME/SYMBOL-корень → frame, INSTANCE → instance, PARAGRAPH → text,
  RECTANGLE/ELLIPSE → rect, VECTOR/BOOLEAN_OPERATION → vector; image-fill → image.
- Структура §7.2: дети по позиции, равные — по порядку массива, «верхний рисуется последним»;
  `visible:false` — узел с поддеревом выбрасывается; несколько корней экрана → синтетическая
  обёртка + `stats.screenRoots`; stray-объекты < 5 % площади крупнейшего корня — выбросить с
  сообщением; корень-определение библиотеки — выбросить с записью; генерик-корень-инстанс →
  fallback; варианты из имени («State=hover, Size=L») → `variants`; автоимена (Frame 123, Group 5,
  TEXT, Rectangle) — помечаются, не переименовываются; icon-only инстанс ≤ 64 px без подписи →
  kind=icon; пустой resolved-инстанс → помеченный placeholder.
- Геометрия: `autoLayout` → layout (direction из `autoLayoutDirection` 1/2 — сверить по фикстуре,
  gap = `autoLayoutItemSpacing`, padding = `autoLayoutPadding*`, align.main/cross из
  `autoLayoutPrimaryAlign`/`autoLayoutCounterAlign`/`autoLayoutAlignType`, wrap); размер ребёнка
  против родителя (`stackChildPrimarySizing`, `stackPrimarySizing`, `stackCounterSizing`:
  FIXED → число, RESIZE_TO_FIT → hug, растяжение → fill); `autoLayoutItemAbsolutePos` → box
  сохраняется; box — только у узлов вне layout-контекста; корень к (0,0).

## Готово, когда
- `test_normalize_pixso.py` на фикстуре: корень «Modal» 600×245 с layout-колонкой; 3 инстанса в
  порядке позиции (y 20, 64, 144); скрытых узлов нет; канон проходит валидацию 1.1; повторная
  нормализация побайтно та же; неизвестный JSON → отказ.

## Результат
`daiver/names.py`, `daiver/ingest/{detect,pixso,normalize}.py`, инструмент `daiver_normalize`;
`test_normalize_pixso.py` (38). Правила адаптера выведены по ДАННЫМ образца (гипотезы проверялись на
геометрии 214 контейнеров) и записаны в README фикстуры и docstring `ingest/pixso.py`.
- Канон фикстуры: корень «Modal» (box 0,0,600,245; size `{w: 600, h: hug}`; column, padding 20,
  align main start / cross center), три инстанса в порядке позиции (y 20, 64, 144), у шапок
  `{fill, hug}`, у блока действий `{600, hug}` (код 0 — как задано в макете); `component.figmaName`
  — имя определения (группа состояний), `variants` — из `propRefMap.variant`, иначе из имени.
- **Решения там, где спека свободна**: `box` — в координатах ЭКРАНА (корень в 0,0), только вне потока;
  порядок детей — по позиции вдоль оси потока, равные — в порядке рисования (последний в массиве
  первым), абсолютные дети контейнера — после потока; корень-инстанс с автоименем становится frame;
  посторонние корни (< 5 %) выбрасываются с сообщением, настоящие — в обёртку `inferred:roots:<id>`.
- **Ингест сам ничего не пишет мимо канона**: хеш файла требования сверяется с манифестом — изменённый
  мимо pull файл отклоняется; в канон кладётся `stats.sourceSha256` (по нему статус 1.10 увидит
  устаревший канон); Figma и неизвестное — названные отказы (X.2).
- **Перенесено в 1.4** (нужно содержимое инстанса): коллапс icon-only инстансов в `kind=icon` (≤ 64 px
  без подписи) и размеченные placeholder'ы пустых инстансов. Краски/шрифты — 1.5, векторный арт — 1.6.
- Не выведено: перенос (wrap) — признака в образце нет; `box` инстансов в потоке не пишется.
