# 1.5 — Pixso → канон: краски, типографика, токены стилей

**Этап:** 1 · **Зависит от:** 1.3 · **Статус:** todo
**Спека:** §7.2 (Краски, Типографика), §6.5, §6.3 (style/font/color) · **INV:** B13 (тексты), основа B18 ·
**QG:** U2, F1

## Зачем
Verify сравнивает цвета, шрифты, радиусы и тени с допусками в 2 единицы — значит, канон обязан
нести их точно и в одной форме для всех источников.

## Что сделать
- Масштаб каналов определяется ОДИН раз на файл (в образце r,g,b — 0..255, a — 0..1); цвет →
  `rgba(…)`, альфа до 3 знаков; невидимые краски (`visible:false`, нулевая непрозрачность)
  пропускаются; несколько заливок — верхняя видимая; image-fill → kind=image.
- Градиент → CSS-gradient со всеми stop'ами; per-corner radius (`rectangle*CornerRadius`) — массив
  только при различии углов; обводка → border (`strokeWeight`, `strokePaints`, `strokeAlign`,
  `border*Weight` по сторонам); тень (`effects` DROP_SHADOW: offset, radius, spread, color) → одна
  строка CSS box-shadow; opacity.
- Типографика: `fontFamily`, `fontSize`, `fontStyle` → вес числом (Regular 400, Medium 500,
  Semibold 600, Bold 700…) и italic по имени; `lineHeightNumber/Unit` (PIXELS/PERCENT/auto);
  `letterSpacingNumber/Unit` (PERCENT → доля размера); `textAutoResize` → hug; цвет текста — из
  заливки узла.
- Токены: `inherit{Fill,Text,Stroke,Effect}StyleID` → имя из `localStyleMap`
  («Static/T&I/Base/Primary», «Text/B1») в `style.tokens`/`font.token`; значения, которых узел
  не несёт, берутся из стиля; значение узла сильнее токена.
