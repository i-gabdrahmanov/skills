# 1.7 — Вывод раскладки (макеты без auto-layout)

**Этап:** 1 · **Зависит от:** 1.3 · **Статус:** todo
**Спека:** §8 (8.1, 8.2), §20.4 (`LAYOUT_TOLERANCE` 1 px, `GAP_JUMP` 1.3) · **INV:** B8 · **QG:** U3, F6

## Зачем
Макет без auto-layout приходит абсолютными x/y. Скопировать — значит получить модуль из
абсолютных div, который пиксельный гейт пропустит, а жить с ним нельзя. Normalize выводит
раскладку и доказывает её реплеем.

## Что сделать
`daiver/ingest/layout.py`, включается `layout.infer` (off/false — выключено):
1. Стек с равным ритмом → column (row) c gap и padding; порядок — по позиции.
2. Cross-ось: center — только если центрирование воспроизводит рамку; общая нижняя кромка → end;
   одинаковая высота и start → без align.
3. Одиночный абсолютный ребёнок → padding родителя.
4. Ритм с округлением: 10 и 11 px — один gap; настоящий разрыв — нет.
5. Две величины зазора → синтетические группы (контейнер, которого нет в макете) с id
   `inferred:<члены>` — re-pull их сохраняет; третья величина вкладывается, а не сплющивается
   (разделительный зазор > группирующего в 1.3 раза).
6. Решётки: одинаковый зазор в обе стороны → одна wrapping row (короткая последняя строка тоже);
   разные зазоры — вложенные ряды; колонка полновесных блоков — не wrapping row.
7. Отказы: перекрытия; контейнер с собственным auto-layout (и pinned-дети); ребёнок вне
   контейнера; выпирание за край; cross-позиции не start/center/end.
- Доказательство: раскладка принимается, только если реплей ставит КАЖДОГО ребёнка на его бокс
  ±1 px; иначе дети остаются абсолютными и узел — в `unproven`. Синтетическая группа — настоящий
  элемент-обёртка. `layout.inferred: true`.
- layoutHints — только КАНДИДАТЫ (применяет resolve, 2.5): `h:fill`/`w:fill` (ребёнок покрывает
  контейнер), `grid` (ряд равновеликих; после wrapped-lattice — high), `main:space-between`
  (только прижатые к обоим краям).
- На макете с настоящим auto-layout ничего не делает.

## Готово, когда
- `test_layout_inference.py` на синтетике по каждому правилу и отказу; F6: реплей сходится ±1 px
  ко всем детям, необъяснимый контейнер остаётся absolute + hints, повторный normalize побайтно
  стабилен, id синтетических групп стабильны.

## Нужно
Реальный полноэкранный кадр без auto-layout — образец модалки целиком на auto-layout.
