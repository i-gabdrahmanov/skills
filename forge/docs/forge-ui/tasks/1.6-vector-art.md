# 1.6 — Векторный арт и svg-ассеты

**Этап:** 1 · **Зависит от:** 1.3 · **Статус:** todo
**Спека:** §7.4, §6.3 (`art`), §13.5 п.6, §20.4 (`ICON_MAX` 64) · **INV:** B7, F5 · **QG:** U1, U23, F5, N6

## Зачем
Экспорт не несёт геометрию путей: иллюстрация приходит десятками шейпов. Её надо склеить в ОДИН
узел-арт, который строится из `.svg`-файла, а не рисуется кодом и не подменяется голым div.

## Что сделать
- `daiver/ingest/art.py` — `collapse_vector_art(root)`: группа шейпов → один узел с
  `art:{slug, nodes}` и id верхушки; одиночный вектор ≤ 64 px — кандидат в иконки, больше —
  арт (вордмарк, лого); НЕ коллапсировать поддерево с текстом, с инстансом, с bitmap, контейнер
  простых прямоугольников (фон), auto-layout контейнер; коллапс на ВЕРХНЕЙ арт-ноде.
- Slug: из осмысленного имени; автоимя → ближайший осмысленный предок; не-ASCII не
  транслитерируется — фолбэк; коллизии двух рисунков разводятся суффиксом.
- `collect_vector_art(root)` — список ассетов из уже схлопнутого дерева.
- Инструмент **`daiver_svg_assets(track, frame?, slug?, svgPath?, moduleDir?)`**:
  регистрация `.svg` (экспорт Pixso, как `Modal.svg` образца) в `<frame>/assets/<slug>.svg`;
  `missingArt` — слаги без файла; с `moduleDir` (используется на 3.2) — копия в модуль и точный
  import + JSX под `svg.render` (component — SVGR-импорт, url — `<img>`, inline). Нет файла — не
  блокер: placeholder правильного размера с меткой slug'а и названным недостающим файлом.

## Готово, когда
- `test_art.py`: веер из N безымянных фигур → одна арт-нода, slug стабилен между прогонами

  `test_svg_assets.py`: регистрация идемпотентна, missingArt перечисляет без файла, JSX для трёх
  режимов `svg.render`.
