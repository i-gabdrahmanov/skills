# 7.2 — Автономный триаж verify

**Этап:** 7 · **Зависит от:** 7.1 · **Статус:** todo
**Спека:** §14.12, §15.4 (таблица interactive vs autonomous) · **INV:** D8, D9, E4, E5, C31, F12 ·
**QG:** P5, N4, N5, N20

## Зачем
Без человека точка решения — триаж агента по каждому дефекту с записанной причиной, а остановка —
только clean, потолок итераций или отсутствие прогресса.

## Что сделать
- Автономный verify: report.html не рендерится; на каждый блокирующий дефект — `fix` (по умолчанию
  для deterministic; значение — из канона/спеки, никогда с картинки) / `skip` (с причиной: размер
  состояния макета, переопределение padding библиотеки, шелл приложения, противоречие спеке) /
  `noise` (артефакт сравнения, с причиной). `daiver_verify_state_record` в автономии отказывает без
  триажа по каждому блокирующему (skip без причины — дефект, который никто не ревьюит).
- Vision-пункт чинится только после собственного подтверждения по картинкам и только как измеренное
  значение или недостающий файл; Minor/noise не «чинятся ради закрытия».
- Стоп: clean; `capReached` (`workflow.autonomous.maxVerifyIterations`, по умолчанию 3, решение
  stop); `progress.stalled` (не лучше прошлой; регресс — тоже).
- Готовый `verify-decisions.json` в папке трека/кадра соблюдается ПЕРВЫМ (skip → declined,
  false_positive → noise) — решения человека автономия не отменяет.
- Таблица §15.4: medium — принят с пометкой `unconfirmed`; low — `resolution: local`
  (`outputDir/local/`, отмечено в плане и отчёте); иконка без маппинга — плейсхолдер с именем;
  предложение правила карты — блок «paste-ready» в отчёте, карта не пишется; URL — из ключей
  директивы, нет — `blocked: no-implementation`; dev-сервер — записанный devCommand (хелпер 4.9),
  нет — `blocked: implementation-unreachable`; модалка без рецепта — `blocked: no-open-recipe`.
- `verify-report.md`: frontmatter outcome + блок `### Триаж` на каждую итерацию (действие и почему
  по каждому дефекту) + кем закончен цикл; затем `daiver_run(finish:true)`.

## Готово, когда
- `test_autonomous_triage.py`: отказ записи без триажа; стоп по cap и stall; решения человека
  соблюдаются; N4 (нет записи конфига/карты, нет report.html, нет init), N5 (low → local), N20
  (vision-пункты не чинятся автономно).

*Заметка (2.5).* Подтверждение резолва сейчас требуется всегда, режим прогона не читается: «спрашивать или нет» решает одна функция
`resolution_report.confirm_reason(rec, threshold, icons_fallback)`, а `resolution_report.write/check` требуют согласия `ui-resolve-<KEY>`. В автономии те
же записи получают `unconfirmed` (medium; иконка-плейсхолдер при `ask` — просто плейсхолдер) и `local` вместо вопроса (low, N5), согласие не требуется,
а блок «Предложенные правила карты» отчёта уже есть («paste-ready»).
