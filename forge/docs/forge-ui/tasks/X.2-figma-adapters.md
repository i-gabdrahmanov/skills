# X.2 — Figma-адаптеры: json-a, json-b, html

**Этап:** сквозная · **Зависит от:** образцы · **Статус:** blocked (нет образцов экспорта)
**Спека:** §7.1, §7.2 · **INV:** B2, F10, A8 · **QG:** U2, F1, N18, S8

## Зачем
Проекты без Pixso дают одноразовый экспорт Figma. Тот же канон, что из Pixso, — и весь пайплайн не
знает источника.

## Что сделать
- `daiver/ingest/figma_a.py` — сырой dump Plugin API (дерево children c fills/strokes/effects);
  `figma_b.py` — предобработанный экспорт (Text-узлы с CSS-подобными стилями, Icon-узлы);
  `figma_html.py` — HTML-экспорт, разбор `html.parser` офлайн (ни одного сетевого запроса).
- Детект в `detect.py` по структуре; правила §7.2 общие с Pixso (материализация — по тому, что
  экспорт несёт); сжатие ≥ 5×; схематически тот же канон.
- Никакого Figma REST API ни в какой форме (S8, F10).

## Готово, когда
- По образцу каждого формата — golden-тест канона (F1); N18 — нормализация html без сети.

## Нужно от пользователя
Реальные обезличенные экспорты каждого формата — без них адаптер пишется по догадке, а спека
запрещает догадки.
