# 1.8 — Outline и section

**Этап:** 1 · **Зависит от:** 1.1, 1.7 · **Статус:** todo
**Спека:** §9 (9.1–9.3), §16 (nodeUrl), §20.4 (outline: maxTextLen 80, MAX_UNPROVEN 60,
MAX_ABSOLUTE_CHILD_IDS 20) · **INV:** B1, B10, B11, B12, F2 · **QG:** U4, F7, N3

## Зачем
Канон большого экрана — 35–45 тыс. токенов, его никто не читает целиком. Resolve планирует по
дайджесту (в 5–6 раз легче), build получает секции, ограниченные по байтам.

## Что сделать
`daiver/outline.py`; инструменты **`daiver_outline(track, frame?, weightBudget?)`** и
**`daiver_section(track, frame?, sectionId)`**:
- Бюджет: аргумент > `workflow.weightBudget` > 24000 (минифицированные байты поддерева); границы
  секций выбирает код (descend-and-partition), порядок документа сохраняется, лист больше бюджета —
  `oversize` целиком, не режется; при большом бюджете — корень целиком.
- `sections[]`: `{id, name, kind, figmaName?, weight, nDescendants, depth, path, hash}` (hash —
  subtree_hash 1.1).
- Компактное дерево: kind/name/weight/nChildren; текст усечён до 80 без эллипсиса; box — только
  у абсолютных; layout/size — где есть.
- `unproven[]`: контейнеры с абсолютными детьми (называя ИХ детей, до 20) и узлы с кандидатами
  layoutHints; один абсолютный ребёнок-overlay — не попадает; двойная причина — дважды; кап 60 с
  честным счётчиком отброшенного; полностью объявленный макет — пусто.
- `goalImage` — путь или null с подсказкой; `nodeUrlTemplate` (Pixso — подмена item-id; Figma —
  node-id через дефис; параметра нет — добавить; путь внутри инстанса — ссылка на инстанс; нет
  URL — голый id; адрес не выдумывается).
- Section: `section` (мета), `ancestors` (flex-контекст цепочки root→parent), `node` (полное
  поддерево ≤ бюджета); понимает ровно те id, что выдаёт outline; неизвестный — ясная ошибка.
  Дельты состояний/ревизий — 6.2/6.3.

## Готово, когда
- `test_outline.py`: секции ≤ бюджета, разрез детерминирован, хеши и buildOrder стабильны между
  прогонами (F7), outline на синтетическом большом экране ≥ 4× легче канона, приоритет бюджета
  аргумент > конфиг > дефолт, unproven по правилам, неизвестный sectionId → ошибка.
